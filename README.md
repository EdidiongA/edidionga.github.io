# edidionga.github.io

Personal portfolio of Edidiong-Abasi Anwanane. Static site, no build step.

## Structure
- `index.html`: the site
- `css/style.css`: styles
- `js/script.js`: navigation, project filters, contact form
- `assets/`: profile image and favicon
- `docs/`: publication PDFs

## Contact form
The form posts to FormSubmit (https://formsubmit.co), which forwards messages to didianwanane@gmail.com with no server or account needed.

First-time activation: after deploying, submit the form once. FormSubmit sends a one-time confirmation email to didianwanane@gmail.com. Click "Activate" in that email. Every message after that is delivered automatically.

## Deploy
Push to the `main` branch of the `edidionga.github.io` repository. GitHub Pages serves it at https://edidionga.github.io/.
